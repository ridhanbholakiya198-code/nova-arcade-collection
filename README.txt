1. Put nova-arcade-final-icon-1024.png in ~/storage/downloads/
2. Put nova-arcade-finalize.sh in ~/storage/downloads/
3. In Termux run:
   cp ~/storage/downloads/nova-arcade-finalize.sh ~/
   bash ~/nova-arcade-finalize.sh

The script updates the final icon, retro SFX, Light/Dark AMOLED appearance, and mobile-safe About submenu, then commits and pushes to main.
